## 🌟 Overview & Concept
**Sky & Shore Beach Resort** (formerly known as Aron Beach Resort) is a coastal and eco-tourism sanctuary situated in **Mansalay, Oriental Mindoro**. The platform is built as an interactive tourism marketing, information management, and customer reservation portal.

## 🚀 How to Deploy on GitHub Pages
1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Sky and Shore Beach Resort"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch **main** and folder **/ (root)**.
   - Click **Save**.
3. Your website will be live in 1-2 minutes at:  
   `https://<your-username>.github.io/<your-repo-name>/`
